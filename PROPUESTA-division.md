# Propuesta: dividir los Términos de DameFlash (BORRADOR, no publicado)

## URLs sugeridas
- `/dameflash-terminos/` → Términos para clientes (el index.html actual v1.4, con un enlace arriba a "¿Tienes un local? Términos para locales").
- `/dameflash-terminos/locales.html` → Términos para locales (borrador en este branch).
- Ambas comparten pie, versión propia y un bloque común "Rol de DameFlash / Datos personales".
- Alternativa: index.html como selector y `clientes.html` + `locales.html` (rompe el enlace actual; no recomendado si ya se envió a Placetopay).

## Partes comunes (idénticas en ambos)
Titular (RUC, RIMPE), DameFlash como intermediario tecnológico, aceptación electrónica (Ley de Comercio Electrónico), uso adecuado y fraude (COIP 186/190), datos personales (LOPDP), cambios con re-aceptación obligatoria, ley aplicable.

## Términos para locales (nuevo: locales.html)

## Diferencias clave
| Tema | Cliente | Local |
|---|---|---|
| Relación | Consumidor (LODC aplica plenamente) | Relación comercial entre proveedores |
| Datos | Nombre, correo, nacimiento, celular, ubicación | RUC, razón social, cuenta bancaria, documentos, dirección/GPS del local |
| Dinero | Paga | Recibe liquidación semanal menos comisión |
| Entrega | Confirma la recepción | Prepara; solo ingresa el código que dicta el cliente |
| Responsabilidad | Uso de su cuenta y código | Producto, higiene, alérgenos, impuestos, menores |
